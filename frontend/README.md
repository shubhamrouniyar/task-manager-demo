# Frontend

React + Vite + TypeScript UI for the task manager demo.

## Local development

```bash
npm install
npm run dev
```

Set `VITE_API_URL` (defaults to `http://localhost:8080`) to point at the Spring Boot API.

## Build

```bash
npm run build
```

## Netlify

This folder is Netlify-ready (`netlify.toml`). Set `VITE_API_URL` in Netlify environment variables to your deployed backend URL before deploying.
